##  Requirements

1. Print numbers from 1 to 100

2. Print all even numbers from 1 to 100

3. Calculate factorial of a number

---

##  Constraints

- Use loops only (`for` or `while`)
- Do NOT use functions
- Take input from user where needed

---

##  Bonus

1. Print multiplication table for a number

```cpp
Enter number: 5
5 x 1 = 5
5 x 2 = 10
...
```

2. Count how many even numbers exist between 1 and n

---

## Expected Concepts

- for loop
- while loop
- loop control
