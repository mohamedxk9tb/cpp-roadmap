## Description

This project provides a set of utilities to work with arrays in C++.

It focuses on implementing core operations manually without relying on built-in functions.

---

## Features

- Reverse array
- Find maximum and minimum
- Rotate array
- Search element

---

## Concepts Used

- Arrays
- Time complexity
- Looping
- In-place operations

---

## How to Run

Compile and run:

```bash
g++ main.cpp -o app
./app
```
