##  Requirements

1. Input 5 numbers into an array

2. Print all elements of the array

3. Find the sum of all elements

4. Find the maximum value

---

##  Constraints

- Use arrays only
- Use loops (`for` or `while`)
- Do NOT use functions

---

##  Bonus

1. Find the minimum value

2. Reverse the array

Example:

```
Input: 1 2 3 4 5
Output: 5 4 3 2 1
```

---

## Expected Concepts

- Arrays
- Loops
- Indexing

---

## Example Output

```
Enter 5 numbers:
1 2 3 4 5

Sum = 15
Max = 5
```

---

##  Challenge

Find the second largest number in the array

Example:

```
Input: 3 7 2 9 5
Output: 7
```
