##  Description

A simple game where the computer chooses a random number, and the user tries to guess it.

---

## Features

- Random number generation
- User input
- Hints (higher / lower)
- Multiple attempts

---

## Concepts Used

- Loops
- If / Else
- Random numbers
- User input

---

##  How it works

1. Computer generates a random number
2. User tries to guess
3. Program tells if guess is too high or too low
4. Loop continues until correct guess

---

## Example

```
Guess the number: 5
Too low!

Guess the number: 8
Too high!

Guess the number: 7
Correct!
```
