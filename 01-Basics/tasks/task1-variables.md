##  Requirements

1. Create variables of the following types:
   - int
   - float
   - char
   - string

2. Assign values to each variable

3. Print all variables using `cout`

---

##  Constraints

- Do NOT use loops
- Do NOT use functions
- Use only what you learned in variables

---

##  Bonus

- Take input from user instead of hardcoding values

```cpp
int age;
cin >> age;
```

---

## Expected Concepts

- Variable declaration
- Data types
- Input / Output

---

## Example Output

```
Age: 20
Price: 99.5
Grade: A
Name: Mohamed
```

Take from user:
