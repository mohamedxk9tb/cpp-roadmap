## Part 1: Concepts (MCQ + Short Answer)

### Theory Questions

1. What is the difference between:
   - `int` and `float`
   - `=` and `==`

2. What will be the output?

```cpp
int x = 5;
if(x = 10){
    cout << x;
}
```

3. Why do we use loops instead of repeating code manually?

4. What is array indexing? And why does it start from 0?

5. What is the difference between:
   - function declaration
   - function call

6. Explain the difference between:
   - `cin >>` and `getline()`
   - C-style strings and C++ string class

7. What is a pointer? How is it different from a reference?

8. What is the difference between:
   - `static_cast` and `dynamic_cast`
   - `enum` and `enum class`
