## Problem 2: Implement Circular Queue

Fix the limitation of normal queue by implementing a circular queue.

### Requirements

- reuse empty spaces  
- use modulo operator

## Problem 3: First Non-Repeating Character

Given a stream of characters, find the first non-repeating character at each step.

### Example

Input:
```
a a b c
```

Output:
```
a -1 b b
```

## Problem 4: Queue using Two Stacks

---

## Hints

- Queue is FIFO  
- Think in terms of order  
- For circular queue → use modulo  
- For two stacks → reverse order

## Challenge
