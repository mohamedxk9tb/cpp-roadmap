##  Requirements

1. Write a program to check if a number is:
   - Even or Odd

2. Write a program to check if a number is:
   - Positive
   - Negative
   - Zero

---

##  Constraints

- Use `if / else` only
- Do NOT use loops
- Take input from user

---

##  Bonus

- Find the largest of 3 numbers

```cpp
int a, b, c;
cin >> a >> b >> c;
```

---

## Expected Concepts

- if / else
- comparison operators
- user input

---

## Example Output

```
Enter number: 5
Odd
```

```
Enter number: -3
Negative
```

##  Challenge

Take 3 numbers from user and print:
