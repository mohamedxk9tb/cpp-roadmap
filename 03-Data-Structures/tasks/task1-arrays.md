## Problem 1: Reverse Array

Given an array of integers, reverse it in-place.

### Constraints

- Do NOT use extra array  
- Time complexity should be O(n)

### Example

Input:
```
[1, 2, 3, 4]
```

Output:
```
[4, 3, 2, 1]
```

## Problem 3: Rotate Array

Rotate array to the right by k steps.

### Example

Input:
```
[1,2,3,4,5], k = 2
```

Output:
```
[4,5,1,2,3]
```
