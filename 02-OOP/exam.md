## Part 1: Concepts (Short Answer)

### Theory Questions

1. What is the difference between:
   - class and object
   - encapsulation and abstraction

2. Why do we use private variables?

3. What is inheritance? Give a real-life example.

4. What is polymorphism? Explain the difference between:
   - overloading
   - overriding

5. What is a pure virtual function?

6. Explain the difference between:
   - constructor and destructor
   - static and instance members

7. What is operator overloading? When should you use it?

8. What is the purpose of a copy constructor?

## Part 2: Coding (OOP Focus)

### Problem 1: Student Class

Create a class `Student`:

- private: name, grade
- public: setter and getter

Add:

- function to display data

---

### Problem 2: Bank Account System

Create class `Account`:

- balance

Functions:

- deposit
- withdraw
- display

Add validation:

- cannot withdraw more than balance

---

### Problem 3: Inheritance System

Create base class `Animal`:

Function:

- speak()

Create:

- Dog
- Cat

Each should have different output

---

### Problem 4: Shape System (Polymorphism)

Create base class `Shape`:

Function:

- area()

Create:

- Circle
- Rectangle

Each calculates area differently

---

### Problem 5: Constructor Practice

Create a class `Rectangle` with:

- Default constructor (1x1)
- Parameterized constructor (width, height)
- Copy constructor
- Function to calculate area and perimeter

---

### Problem 6: Static Counter

Create a class that:

- Tracks number of objects created
- Uses static member variable
- Provides static method to get count

---

### Problem 7: Operator Overloading

Create a class `Complex` with:

- Real and imaginary parts
- Overload + and - operators
- Overload << for output
