##  Requirements

1. Create a function to:
   - Add two numbers

2. Create a function to:
   - Find the maximum of two numbers

3. Call both functions inside `main()`

---

##  Constraints

- Use functions only
- Do NOT use global variables
- Use input from user

---

##  Bonus

Create a simple calculator using functions:

- Add
- Subtract
- Multiply
- Divide

Example:

```
Enter choice:
1. Add
2. Subtract
3. Multiply
4. Divide
```

## Expected Concepts

- Function declaration
- Function call
- Parameters and return values

## Example Output

```
Enter two numbers:
5 3

Sum = 8
Max = 5
```
