## Problem 1: Insert at Beginning

Create a linked list and insert a new node at the beginning.

### Requirements

- Define Node structure  
- Update head correctly  

---

## Problem 2: Insert at End

Insert a node at the end of the linked list.

### Constraints

- Traverse the list manually  
- Do NOT use STL  

---

## Problem 3: Delete Node by Value

Delete the first node that contains a given value.

### Example

Input:
```
List: 10 → 20 → 30 → 40
Value: 20
```

Output:
```
10 → 30 → 40
```

---

## Problem 4: Search in Linked List

Check if a value exists in the list.

### Output

- return true or false  

---

## Problem 5: Reverse Linked List (Important)

Reverse the entire linked list.

### Example

Input:
```
10 → 20 → 30
```

Output:
```
30 → 20 → 10
```

---

## Hints

- Use pointers carefully  
- Track previous, current, next  
- Draw the list before coding  

---

## Challenge

- Reverse the list without using extra memory  
- Handle edge cases:
  - empty list  
  - one element  

---

## Common Mistakes

- losing the head pointer  
- breaking links  
- null pointer access
