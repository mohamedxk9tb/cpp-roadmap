##  Description

A simple login system where the user enters a username and password, and the program checks if they are correct.

---

## Features

- Username & password input
- Validation using if / else
- Limited attempts

---

## Concepts Used

- If / Else
- Loops
- Strings
- User input

---

##  How it works

1. User enters username and password
2. Program compares with stored values
3. If correct → access granted
4. If wrong → try again

---

## Example

```
Enter username: admin
Enter password: 1234

Access Granted
```
