## Description

This project simulates a real-world queue system.

It demonstrates how elements are processed in FIFO (First In, First Out) order.

---

## Features

- Enqueue (add element)
- Dequeue (remove element)
- Display queue
- Circular queue behavior

---

## Concepts Used

- Queue (FIFO)
- Circular array
- Index management (front / rear)
- Simulation logic

---

g++ main.cpp -o app
