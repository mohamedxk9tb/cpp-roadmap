## Problem 2: Check Balanced Parentheses

Given a string containing parentheses `()`, check if it is valid.

### Example

Input:
```
(())()
```

Output:
```
Valid
```

Input:
```
(()(
```

Output:
```
Invalid
```

## Problem 3: Reverse String using Stack

## Problem 4: Minimum Element in Stack

Design a stack that supports:

- push  
- pop  
- getMin  

All in O(1)

---

## Hints

- Stack works LIFO  
- Use push/pop carefully  
- For getMin → think auxiliary stack  

---

## Challenge

- Implement stack using linked list
