## Description

This project implements a linked list from scratch in C++.

It allows managing a dynamic list of elements without using STL.

---

## Features

- Insert at beginning
- Insert at end
- Delete by value
- Search element
- Reverse list
- Display list

---

## Concepts Used

- Pointers
- Dynamic memory allocation
- Linked List operations
- Traversal

---

## How to Run

```bash
g++ main.cpp -o app
./app
```
